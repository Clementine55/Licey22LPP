# Лицейский Портал Печати (ЛПП)

Единый веб-интерфейс для работы с документами и их отправки на физические принтеры лицея. Система интегрирована с файловым хранилищем Seafile и сервером конвертации OnlyOffice.

## 🚀 Возможности
* **Интеграция с Seafile:** Прямой доступ к личным и групповым библиотекам по API (без необходимости скачивать файлы на ПК).
* **Конвертация на лету:** Автоматическое преобразование Word/Excel/PowerPoint в PDF силами OnlyOffice Document Server с сохранением форматирования (поля, ориентация, масштаб).
* **Умная печать:** Взаимодействие с сервером CUPS. Поддержка двусторонней печати, выбора лотков (A3/A4/Letter), обрезки по страницам.
* **Мониторинг:** Опрос состояния CUPS-принтеров перед отправкой задания (проверка сети, пинг, статус очереди).

## 🏗 Архитектура и Стек
* **Backend:** Python 3.10+, FastAPI, Uvicorn.
* **Frontend:** Vanilla JS, HTML5, CSS3 (без тяжелых фреймворков), концепция SPA.
* **Интеграции:**
  * `requests` для REST API Seafile и OnlyOffice.
  * `pypdf` для манипуляций с PDF (вырезка страниц).
  * Подсистема `lp` / `lpstat` для связи с Linux CUPS.

## ⚙️ Установка и запуск

1. **Системные зависимости:**
   На сервере должна быть установлена и настроена система CUPS с добавленными принтерами. У пользователя, от имени которого работает сервис, должны быть права на выполнение команд `lp` и `lpstat`.

2. **Окружение:**
   Клонируйте репозиторий и установите Python-зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. **Конфигурация:**
   Создайте файл `.env` в корне проекта:
   ```env
   SERVER_URL=https://лис.лицей22.рф
   ONLYOFFICE_URL=https://onlyoffice.ваш-домен
   ONLYOFFICE_JWT_SECRET=ваш_секретный_ключ
   ```

4. **Запуск:**
   ```bash
   uvicorn main:app --host 0.0.0.0 --port 8000
   ```

## 📂 Структура проекта
* `main.py` — Точка входа FastAPI, маршруты API.
* `services.py` — Бизнес-логика (конвертация OnlyOffice, обработка PDF).
* `static/` — Статика фронтенда (HTML, CSS, JS модули).
* `temp_downloads/` — Временная директория для промежуточных файлов (очищается автоматически).
